# IT-QUIZ

An interactive quiz application focused on IT and computer science knowledge assessment.

## 📋 Description

IT-QUIZ is a web-based quiz platform designed to test and improve knowledge in Information Technology, programming, networking, databases, and related fields.

## 🏗️ Technology Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP/Node.js
- **Database**: MySQL/MongoDB

## 🚀 Features

- 📝 Multiple-choice questions
- ⏱️ Timed quizzes
- 📊 Score tracking and analytics
- 👥 User profiles and leaderboards
- 🎯 Difficulty levels
- 📈 Progress tracking
- 🏆 Achievement badges

## 📦 Installation

### Prerequisites
- Node.js 12+ (or PHP 7.4+)
- npm/yarn
- Database system

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/Lahcen-akdime/IT-QUIZ.git
   cd IT-QUIZ
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment**
   ```bash
   cp .env.example .env
   ```

4. **Setup database**
   ```bash
   npm run db:migrate
   npm run db:seed
   ```

5. **Start the server**
   ```bash
   npm start
   ```

The application will be available at `http://localhost:3000`
